Fonts used by the sticky pipeline (bundled so every machine renders the same):

- `Poppins-Bold.ttf` — Poppins by Indian Type Foundry, SIL Open Font License 1.1 (Google Fonts).
- `LiberationMono-Bold.ttf` — Liberation Mono, SIL Open Font License 1.1 (see `LiberationMono-COPYRIGHT.txt`).
  Code that asks for "Courier New" gets this font, which is what it always resolved to.
