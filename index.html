How a sticky short gets made

  1. Add the title here. GitHub opens with it filled in. Click Commit changes.
  2. Claude researches and writes the narration, with a strong hook, fast pacing and a loop.
  3. The card says Needs audio. Tap Copy narration, paste it into ElevenLabs and download the MP3.
  4. Tap Upload narration audio and drop the MP3 in. Click Commit changes. Not happy with the words? Use Rewrite narration first.
  5. Claude makes the video to fit your audio. It appears on the card when it's ready. Ask for changes with Request a revision.

How a short gets made

  1. Add it here. GitHub opens with your request filled in. Click Commit changes to save it.
  2. Production starts by itself. Claude picks it up on GitHub within a minute or two. To kick it off again by hand, use Run the queue → Run workflow.
  3. Watch it move. Stage, progress and time left update on the card while Claude works. A 15-second short takes roughly 2 to 3 hours, mostly rendering.
  4. Review and revise. Play it, download it, or write what to change. Each revision becomes a new version.
